## Generated topology and authored raster

`generate-classic-quilting-fixed-raster` decodes the checked CQA ABI, verifies
that triangle vertices stay within the selected patch, preserves triangle and
winding order, and emits f32 literals that round-trip exactly. For
`direct-seed42-k1-1-1.cqa`, patch zero is:

```text
source vertices     3
source triangles    1
indexed topology    [0, 1, 2]
expanded vertices   3
Fe topology type    TriangleList<3>
expanded stream     A, B, C
```

The generated file owns both the stream and
`FixedTopology = TriangleList<3>`, so the authored actor does not repeat the
draw cardinality. A unit test and the generator command below compare the
generated bytes directly with the committed Fe source.

`classic_quilting_fixed_raster` has one resource-free authored raster pass.
Its vertex entry evaluates the curved three-control QB patch and emits ten f32
lanes per vertex: clip `xyzw`, surface position `xyz`, and analytic normal
`xyz`. The typed position and normal cross the raster interface as six WGSL
varying locations and are both consumed by the fragment entry. Bundle
structure is frozen at one pass, draw count 3, no bindings, vertex entry
`vertices`, and fragment entry `shade`.

## Vector oracle

The CPU authority decodes the frozen fixture and evaluates the same controls
with read-only Rust `QBTriPatch::eval_differential` in f64. It independently
forms and normalizes the tangent cross product, then deliberately narrows the
ten expected lanes to the Fe f32 contract.

The Wasm gate compiles the Fe `vertices` entry, validates the module, rejects
unexpected imports, executes all three vertex indices in Wasmtime, and compares
all 30 lanes. The WGSL gate first parses and validates the complete authored
raster with Naga browser capabilities. For numerical readback it retains the
generated vertex function body unchanged, removes only raster entry/interface
attributes, and invokes that body from a small compute capture wrapper. wgpu
dispatches all three vertices through Vulkan llvmpipe and compares the same 30
lanes. Both backends use an absolute tolerance of `4e-6` and reject nonfinite
results.

The GPU gate is strict by default. `MB2_ALLOW_GPU_SKIP` exists only for an
explicitly requested non-gating environment; it was not set for the evidence
run. The final adapter was `llvmpipe (LLVM 21.1.8, 256 bits)`.

The Quilting-hosted transplant names this opt-out
`QUILTING_FE_ALLOW_GPU_SKIP`; the strict default is unchanged.
