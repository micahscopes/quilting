  predecessors;

  authoritative host restart;

## Next integration boundary

Use the host-issued read-only handle for reactive observation and introduce
`hhhs-session` through a narrow authored-session service. Prediction,
persistence, projection, announcement, repair, and peer acknowledgement must
remain separately observable; no session or network work belongs in the
render loop.
